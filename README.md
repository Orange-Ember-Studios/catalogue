# Orange Ember Studios — Catálogo de diseños web

Demonstraciones reales de páginas web para prospectos de Orange Ember Studios.

## Estructura

- `index.html` — galería con enlaces a cada demo
- `plantillas/` — páginas de ejemplo autocontenidas (HTML + CSS inline, sin dependencias)

| Demo | Segmento |
|---|---|
| [boutique.html](plantillas/boutique.html) | Tienda de ropa femenina |
| [calzado.html](plantillas/calzado.html) | Zapatería |
| [formal.html](plantillas/formal.html) | Sastrería / formal wear |
| [artesanal.html](plantillas/artesanal.html) | Accesorios artesanales |
| [estetica.html](plantillas/estetica.html) | Estética y belleza |
| [cafe.html](plantillas/cafe.html) | Cafetería |

## Uso

Publicado en GitHub Pages:
https://orange-ember-studios.github.io/catalogue/

Para crear una variante para un prospecto concreto: copia la demo más cercana a su giro,
renombra la marca, ajusta colores de `:root` y sustituye números de WhatsApp y categorías.
